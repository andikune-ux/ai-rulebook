# Testing Guide

Pilih test berdasarkan arsitektur dan risiko: unit untuk logika terisolasi, integration untuk batas antar komponen, contract untuk API, end-to-end untuk alur pengguna, serta security/performance tests bila relevan.

Gunakan command yang didefinisikan proyek. Jangan mengarang command. Catat versi runtime, environment, hasil, dan test yang tidak dijalankan. Jangan mengubah test agar kegagalan tampak sukses.
