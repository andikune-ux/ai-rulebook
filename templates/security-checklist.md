# Security Checklist

- [ ] No secrets or credentials in source, logs, artifacts, or docs.
- [ ] Authentication and authorization checked server-side where applicable.
- [ ] Input validation and output encoding are appropriate.
- [ ] Dependencies and licenses reviewed.
- [ ] Sensitive data collection, retention, and access minimized.
- [ ] Permissions and capabilities are least-privilege.
- [ ] Error/log output does not expose sensitive information.
- [ ] Production and release changes have explicit approval.
- [ ] Backup, migration, and recovery considered for data changes.
