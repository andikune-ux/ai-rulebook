# Release Checklist

- [ ] Release scope and version confirmed.
- [ ] Required approvals obtained.
- [ ] Tests, lint, build, and security checks passed.
- [ ] Secrets and signing identity verified without exposing values.
- [ ] Database migration and compatibility reviewed.
- [ ] Artifact provenance and checksum recorded where supported.
- [ ] Release notes and known issues prepared.
- [ ] Rollback/forward-fix plan available.
- [ ] Deployment verified after release.
