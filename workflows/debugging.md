# Workflow: Debugging

1. Reproduksi atau identifikasi bukti error; jangan mengarang reproduksi.
2. Periksa log tanpa menampilkan secret/data sensitif.
3. Bentuk hipotesis dan uji satu per satu.
4. Temukan root cause sebelum menambah workaround.
5. Perbaiki dengan diff minimal dan regression test.
6. Laporkan penyebab, perbaikan, validasi, dan batasan.
