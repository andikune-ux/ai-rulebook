# Workflow: Development

1. Pahami requirement dan acceptance criteria.
2. Baca file dan call sites yang relevan.
3. Klasifikasikan risiko perubahan.
4. Buat perubahan minimal yang koheren.
5. Jalankan formatter, lint, type check, dan test relevan.
6. Audit diff, security, compatibility, dan dokumentasi.
7. Laporkan hasil dengan template laporan.
