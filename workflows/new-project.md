# Workflow: New Project

1. Inspeksi repository dan instruksi.
2. Deteksi platform, stack, runtime, package manager, database, dan target deployment.
3. Identifikasi requirement, constraints, dan existing architecture.
4. Buat project profile dari `templates/project-profile.yml`.
5. Tentukan threat/risk profile dan test strategy.
6. Minta approval untuk keputusan HIGH risk.
7. Implementasikan fondasi minimum, test, dan dokumentasi.
8. Laporkan asumsi serta item NOT RUN.
