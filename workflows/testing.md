# Workflow: Testing

1. Deteksi test runner dan command dari konfigurasi proyek.
2. Pilih test sesuai area dan risiko perubahan.
3. Jalankan test tanpa melemahkan konfigurasi.
4. Simpan ringkasan output dan exit status.
5. Klasifikasikan hasil PASS/FAIL/NOT RUN/NOT APPLICABLE.
6. Laporkan flakiness atau keterbatasan environment.
