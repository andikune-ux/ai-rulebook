# Web Platform Rules

- Deteksi framework, bundler, runtime, dan package manager dari lockfile/config yang ada.
- Jangan mencampur package manager atau mengganti lockfile tanpa alasan dan approval yang sesuai.
- Terapkan output encoding, CSP, secure cookies, CSRF protection, dan server-side authorization sesuai arsitektur.
- Jangan menaruh secret server di bundle client.
- Uji responsive layout, accessibility, browser support, loading/error/empty states, dan performance.
- Periksa dependency dan build production.
