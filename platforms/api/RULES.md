# API and Integration Rules

- Definisikan schema, validation, authentication, authorization, dan error contract secara eksplisit.
- Gunakan versioning dan backward compatibility untuk consumer yang sudah ada.
- Terapkan rate limit, pagination, timeout, idempotency, dan observability sesuai kebutuhan.
- Jangan mengekspos internal service atau credential.
- Uji contract dan negative cases; dokumentasikan breaking changes.
