# Contributing

1. Baca `AGENTS.md` atau `CLAUDE.md` sebelum mengubah file.
2. Buat perubahan sekecil mungkin dan jelaskan alasan setiap dependency baru.
3. Jangan mengubah signing configuration, workflow release, script versi, atau `gradle.properties` tanpa instruksi eksplisit pemilik.
4. Jangan commit secret, keystore, hasil build, cache, atau file lokal.
5. Periksa Markdown, shell script, dan YAML sebelum mengirim perubahan.
6. Sinkronkan `AGENTS.md` dan `CLAUDE.md` setiap kali aturan AI berubah.
7. Catat perubahan yang terlihat oleh pengguna di `CHANGELOG.md`.
