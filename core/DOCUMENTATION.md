# Documentation Rules

- Perbarui README, API docs, configuration examples, dan migration notes saat perilaku berubah.
- Dokumentasikan setup, environment variables (nama saja), test, build, deploy, dan rollback.
- Tandai contoh yang belum diverifikasi.
- Catat keputusan arsitektur berdampak besar dan alasan penyimpangan dari standar.
- Jangan memasukkan credential, data pribadi, atau detail kerentanan yang belum ditangani.
