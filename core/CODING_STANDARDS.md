# Coding Standards

- Ikuti formatter, linter, naming, dan style yang sudah ditetapkan repository.
- Gunakan tipe eksplisit dan validasi batas input sesuai bahasa.
- Hindari duplikasi, dead code, global mutable state yang tidak perlu, dan abstraksi prematur.
- Pisahkan tanggung jawab secara proporsional; jangan memaksakan arsitektur tertentu.
- Tangani error secara eksplisit; jangan menelan exception atau error.
- Hindari hardcoded environment-specific values dan secrets.
- Jaga kompatibilitas API dan schema; dokumentasikan breaking changes.
- Tulis komentar untuk alasan/constraint, bukan mengulang kode.
- Jangan melakukan mass reformat tanpa kebutuhan.
